# AI Skill Library

This repository contains a compact summary of AI agent skills and review tools collected from the provided document.

## Structure

- `index.html` – browser-based overview with filtered tables
- `data/skills.json` – structured dataset used by the page

## Launch

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Content categories

- Context Shaping
- Main Flow Shaping
- Upkeep
- Productivity

## Notes

The data reflects the provided research summary and is intended as a practical shortlist for evaluating skills and tooling across Claude Code, Codex, Cursor, GitHub Copilot, Greptile, Qodo, and related platforms.
